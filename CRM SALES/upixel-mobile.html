Sim. Suporta Evolution API (qualquer número via QR Code) e Meta Official API (WhatsApp Business com CNPJ).

Sim. Compatibilidade nativa com Kommo: importação via JSON, mapeamento automático e migração zero-downtime.

Anti-bloqueio com throttling configurável, intervalo aleatório e rotação de instâncias. Para máxima segurança: Meta Official API com templates aprovados.

Não. O builder é 100% drag-and-drop. Templates prontos para os casos mais comuns.
