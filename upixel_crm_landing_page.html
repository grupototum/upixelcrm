FAQ

Perguntas frequentes

O uPixel funciona com WhatsApp pessoal ou precisa do WhatsApp Business?+
O uPixel suporta ambos os modelos: Evolution API (que conecta qualquer número via QR Code, inclusive pessoal) e a Meta Official API (WhatsApp Business com CNPJ). Você escolhe qual usar dependendo da sua operação e volume de mensagens.
Posso migrar minha base do Kommo para o uPixel?+
Sim. O uPixel tem compatibilidade nativa com Kommo: importação de automações via JSON, mapeamento automático de triggers e ações, e migração zero-downtime. Você não perde histórico nem configurações.
O sistema pode ser bloqueado pelo WhatsApp por uso de disparos?+
O uPixel inclui sistema anti-bloqueio com throttling configurável (mensagens por hora), intervalo aleatório entre envios, rotação de instâncias e detecção automática de números inválidos. Para máxima segurança, recomendamos a Meta Official API com templates aprovados.
Preciso de um developer para usar as automações?+
Não. O Visual Workflow Builder é completamente drag-and-drop. Você cria fluxos complexos com IF/ELSE, loops, delays e integrações de API sem escrever código. Há também templates prontos para os casos de uso mais comuns.
O uPixel é LGPD compliant?+
Sim. A plataforma inclui criptografia de dados sensíveis, direito ao esquecimento, exportação de dados do titular, auditoria completa de acesso, opt-out automático e blocklist global. Desenvolvido seguindo os requisitos da LGPD desde a arquitetura.
Como funciona o período de teste?+
14 dias com acesso completo ao plano Pro, sem precisar de cartão de crédito. Após o período, você escolhe o plano mais adequado ou cancela sem custo algum.
