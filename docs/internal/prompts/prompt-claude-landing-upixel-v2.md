## 🎨 COMPONENTES VISUAIS DO 21ST.DEV (INSPIRAÇÃO)

Não instale pacotes npm nem use React. **Recrie os efeitos visuais em CSS puro + JavaScript vanilla**, adaptando para o dark theme do uPixel.

### 1. CPU Architecture (svg-ui)

**Conceito:** Chip central conectado a nós por linhas animadas.  
**Uso na LP:** Hero background ou seção de funcionalidades ("Todas as mensagens em um só lugar").

**Adaptação:**
- Centro: Ícone de inbox/chat (não CPU)
- Nós ao redor: Ícones dos 6 canais (WhatsApp, Instagram, Facebook, Gmail, Webchat, etc.)
- Linhas conectando ao centro com animação de "pulso de dados" (SVG stroke-dashoffset)
- Cores: gradiente de `--u-accent` para `--u-accent2`
- Efeito: Nós piscam suavemente em sequência (loop infinito)

**Implementação técnica:**
```html
<!-- SVG posicionado absolutamente no hero, opacity 0.15 como background -->
<svg class="hero-network-bg" viewBox="0 0 800 600">
  <!-- Linhas animadas -->
  <path class="connection-line" d="M400,300 L200,150" />
  <path class="connection-line" d="M400,300 L600,150" />
  <!-- Nós com círculos pulsantes -->
  <circle class="network-node" cx="200" cy="150" r="20" />
  <circle class="network-node" cx="600" cy="150" r="20" />
  <!-- Centro -->
  <circle class="network-center" cx="400" cy="300" r="40" />
</svg>
```

```css
.connection-line {
  stroke: url(#gradient-accent);
  stroke-width: 2;
  stroke-dasharray: 10 5;
  animation: dataFlow 2s linear infinite;
}
@keyframes dataFlow {
  to { stroke-dashoffset: -30; }
}
.network-node {
  fill: var(--u-accent);
  animation: nodePulse 3s ease-in-out infinite;
}
.network-node:nth-child(2) { animation-delay: 0.5s; }
.network-node:nth-child(3) { animation-delay: 1s; }
/* etc */
```

### 2. Dock Tabs (aliimam)

**Conceito:** Barra de dock estilo macOS com ícones redondos coloridos e animação hover (scale + glow).  
**Uso na LP:** Substitui a lista de "6 canais num único inbox" no HERO ou na seção de funcionalidades.

**Adaptação:**
- 6 ícones representando os canais: WhatsApp (verde), Instagram (roxo/rosa), Facebook (azul), Gmail (vermelho), Webchat (laranja), Messenger (azul claro)
- Hover: ícone escala para 1.2x, adiciona glow da cor do canal, label aparece acima
- Animação de entrada sequencial (stagger 0.1s)
- Posicionamento: centralizado abaixo do HERO ou como elemento decorativo na seção de funcionalidades

**Uso na LP:** Depoimentos ou citações de destaque nas seções de Use Cases.

**Adaptação:**
- Fundo: Dot pattern em `var(--u-border)` com opacidade 0.3
- Citação centralizada com tipografia grande
- Palavras-chave em destaque com gradiente de `--u-accent` para `--u-accent2`
- Bordas com cantos arredondados grandes (24px)
